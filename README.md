## 🌟 Описание проекта

**Telegram Bot Control Panel** — это веб-панель управления и мониторинга ботов в экосистеме умного дома и семейных сервисов.

Панель решает ключевую проблему: как управлять ботом, видеть его логи и тестировать ответы без необходимости заходить на сервер через консоль.

### Ключевые возможности:
- 📊 **Дашборд метрик**: подсчет обработанных сообщений, активных подписчиков, аптайма и режима работы (Long Polling / Webhook).
- 💬 **Встроенный веб-эмулятор Telegram**: возможность отправлять команды (`/start`, `/status`, `/ping`, `/backup`) прямо из интерфейса и моментально видеть форматированные ответы бота.
- 📢 **Модуль массовых оповещений (Broadcast)**: отправка системных уведомлений и срочных семейных алертов всем зарегистрированным пользователям.
- 📜 **Живой журнал событий (Live Logs)**: вывод системных логов с цветовой маркировкой уровней (`INFO`, `SUCCESS`, `WARN`, `ERROR`).
- 🔄 **Управление жизненным циклом**: кнопки мгновенного перезапуска или остановки ядра бота.

## 🚀 Быстрый запуск

### Запуск в 1 клик (Windows):
Дважды щелкните по:
```bash
start.bat
```
*(Панель запустится и откроет страницу `http://localhost:8004`)*.

### Запуск вручную:
```bash
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8004
```

## 🖥 Зачем этому проекту нужен выделенный сервер 24/7?

Telegram-бот — это классический сетевой сервис, который полностью теряет смысл без круглосуточного сервера:

1. **Непрерывный Long Polling / Webhook 24/7**:
   - Если компьютер выключен, бот не отвечает на сообщения, а Telegram накапливает запросы с тайм-аутом ошибки. Выделенный сервер обеспечивает мгновенный ответ в любое время суток.
2. **Экстренные аварийные алерты ночью**:
   - При протечке воды, обрыве интернет-провайдера или попытке несанкционированного входа сервер обязан прислать экстренное пуш-уведомление в Telegram независимо от того, спит ли владелец дома.
3. **Изолированный фоновый процесс**:
   - Бот не должен зависеть от перезагрузок Windows во время игр или тяжелых задач. Серверный демон в Linux/Docker гарантирует 99.9% аптайм.
